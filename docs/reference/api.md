# API reference

[Documentation](../README.md) · [Configuration](configuration.md)

The authoritative request/response schemas are generated by [FastAPI](../../services/backend/tactiq/presentation/api/main.py): `/openapi.json` and interactive `/docs` on the backend. This page indexes contracts rather than duplicating every field.

## Reference endpoints

| Method and route | Purpose |
| --- | --- |
| `GET /health/live`, `/health/ready` | Process and reference-runtime readiness |
| `GET /api/v1/capabilities` | Configured features/locale voice pairs, not remote-provider health |
| `GET`, `POST /api/v1/session` | Session status / credential exchange |
| `POST /api/v1/session/logout` | Clear browser session |
| `GET /api/v1/scenarios` | Available scenario recipes |
| `GET`, `POST /api/v1/matches` | Tenant-owned matches / create scenario |
| `POST /api/v1/matches/{id}/start`, `/pause` | Start/resume or pause preparation |
| `GET /api/v1/matches/{id}/state`, `/events`, `/insights`, `/overlay`, `/replay` | Authoritative football state/evidence/replay |
| `POST /api/v1/matches/{id}/viewer-profile` | Presentation preferences |
| `POST /api/v1/video/jobs`, `/api/v1/video/jobs/from-link` | Bounded asynchronous upload/link analysis |
| `GET /api/v1/jobs/{id}`, `POST /api/v1/jobs/{id}/cancel` | Owned job status/cancellation |
| `POST /api/v1/cv/ingest/upload` | Standalone track extraction; truncation is reported |
| `POST /api/v1/matches/{id}/narratives`, `/recap`, `/commentary/dual` | Grounded representations |
| `POST /api/v1/speech/synthesize`, `/synthesize-dual` | Single/ordered dual audio |
| `GET /api/v1/matches/{id}/commentary/debug` | Analyst/admin orchestration audit |
| `GET /api/v1/matches/{id}/media/source` | Authorized source with range playback |
| `GET /media/{match_id}/{filename}` | Registered match-owned clip; use the returned URL |
| `DELETE /api/v1/matches/{id}` | Admin removal of an inactive match and its media |
| `GET /api/v1/operations/status`, `/metrics`, `/prometheus` | Admin operational samples and alerts |
| `WS /api/v1/ws/matches/{id}` | Live updates; use state/replay resynchronization on slow-consumer signals |

Legacy synchronous `POST /api/v1/video/upload` and `/video/from-link` remain for compatibility. Prefer jobs for new integrations.

## Contract notes

- Authenticate according to the [reference access model](../operations/privacy-and-security.md). Foreign-tenant or unknown well-formed IDs return 404. Malformed match/job path IDs return 400.
- Request-model violations return 422. Semantic Speech errors (identical voices, incompatible language, invalid prosody) return 400.
- Explicit narrative/commentary IDs must be nonblank, whitespace-free, and at most 256 characters. Omit an optional insight ID for latest eligible evidence; an empty ID is not an alias.
- `analysis_mode="cv"` is the video default. `events` is an explicit development compatibility preview, not observed football analysis. YouTube requests require `rights_confirmed=true`.
- CV options govern sampled duration, colors, attack directions, and measured calibration. Default sampling is 8 FPS/180 seconds; maximum analyzed duration is 600 seconds.
- Replay `after_sequence` returns incremental updates; no cursor requests full history. Unknown video score remains unknown.
- Commentary supports `depth="broadcast"`/`"deep"`, `at_ms`, and explicit `overview=true`. Ordered `turns` coexist with legacy primary/secondary fields.
- Provider/fallback metadata is part of the result. Do not interpret successful HTTP transport as genuine model or Speech execution.

Cloud identity/quota/job contracts under development are not declared externally available until integrated and verified.
